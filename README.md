# 🎬 AnimeVault

A full-stack anime discovery and watchlist web application built with vanilla JavaScript, PHP, and MySQL. Search thousands of anime titles via the AniList GraphQL API, build a personal watchlist, and manage your account with secure authentication.

![AnimeVault](docs/screenshots/home.png)

---

## ✨ Features

- 🔍 **Live Anime Search** — powered by the AniList GraphQL API
- 🔥 **Trending & Top Rated** — discover what's popular right now
- 📖 **Anime Details** — scores, episodes, synopsis, genres, and more
- 📌 **Personal Watchlist** — save anime per user account
- 🔐 **Secure Auth** — bcrypt password hashing + Bearer token sessions
- 💾 **Persistent Sessions** — stay logged in across page reloads
- 📱 **Responsive Design** — works on desktop, tablet, and mobile
- 🌙 **Modern Dark UI** — clean, minimal, accessible

---

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| **Frontend** | HTML5, CSS3, Vanilla JavaScript (ES6+) |
| **Backend** | PHP 8.2 |
| **Database** | MySQL / MariaDB |
| **API** | AniList GraphQL |
| **Auth** | Bearer token sessions with bcrypt |
| **Server** | Apache (XAMPP for local dev) |
